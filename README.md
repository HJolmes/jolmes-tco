# Jolmes TCO — Vertriebstool

Interaktives Tool zur Visualisierung versteckter Mehrkosten bei nicht-zertifizierten Gebäudedienstleistern. Vergleicht Total Cost of Ownership mit dem Jolmes-Angebot.

## Lokal entwickeln
npm install
npm run dev
→ http://localhost:5173

## Build
npm run build → erzeugt /dist

## Deployment
Push auf main → GitHub Actions deployt automatisch auf GitHub Pages.
Live: https://hjolmes.github.io/jolmes-tco/

## Hinweis
Repo öffentlich (GitHub Free). Live-Seite ist öffentlich erreichbar, aber via robots-noindex von Suchmaschinen ausgeschlossen.
